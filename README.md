# Drill Track – Sonatrach

##  About the Project
Drill Track is a web platform developed in collaboration with **Sonatrach** as part of our 2CS academic project.  
The platform aims to **centralize drilling reports**, make them easier to search, and provide **data visualization** for better decision-making.

---

##  Features
- 📂 Import and manage drilling reports   
- 📊 Interactive data visualization (charts, statistics)  
- 👥 User management (admin & engineers)  
- 🌐 Modern and responsive interface built with React  

---

## 🏗️ Architecture
The project follows a modular architecture:

- **Frontend**: React + TailwindCSS  
- **Backend**: Django REST Framework  
- **Database**: oracle 

---

## 💻 Tech Stack
- React  
- TailwindCSS  
- Django REST Framework  
- oracle db    

---

## ⚙️ Installation & Usage
```bash
# Clone the repository
git clone https://github.com/Ahlem11elkorichi/drill-track.git
cd drill-track

# Backend
cd backend
pip install -r requirements.txt
python manage.py runserver

# Frontend
cd frontend
npm install
npm start
